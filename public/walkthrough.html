01

Trust the bundle you load

Plugins can start hooks and local MCP processes. This app loads only the included trusted classroom code and fixed paths. The browser cannot select arbitrary plugins.

02

Optional manifest

The manifest declares a stable name and version, but layout can supply components without it. classroom-lite demonstrates this observed loader behavior.

03

MCP and agent evidence

The app records the plugin’s discovered coach definition and connected local stdio server. It does not invoke a subagent or the MCP tool. The hook receipt, however, comes from an actual executed SessionStart process.

04

MCP configuration

strictMcpConfig is false here so the plugin’s packaged MCP definition can load. Homes and SDK configuration are private; filesystem setting sources are empty and claude.ai MCP is disabled. Model tool guards still reject every target except the project manifest.

05

Troubleshooting

Check root path, JSON syntax, readability, existence, namespace and skills/name/SKILL.md. The SDK may report missing paths in plugin_errors while continuing the ordinary conversation. Built-in plugins may still be listed.

06

Local paths and distribution

The SDK receives local directories. Download a marketplace or repository plugin before passing its local root. The app demonstrates sharing one local directory across two projects; it does not publish a marketplace plugin.
