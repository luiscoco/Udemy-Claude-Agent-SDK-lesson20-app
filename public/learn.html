What you will learn.

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Package reusable capabilities

A local plugin can bundle skills, agent definitions, hooks and MCP servers. Inspect the actual classroom bundle in the file viewer.

02

Load local roots explicitly

Pass plugins: [{type: "local", path}]. Compare an absolute path with a path relative to the query cwd. The path must identify the plugin root; tilde expansion and marketplace downloading are not performed here.

03

Verify actual initialization

Inspect init.plugins, skills, slash_commands and plugin_errors. The app also records agent discovery and actual MCP connection metadata. Built-in plugin entries can appear independently.

04

Dispatch namespaced skills

Send /classroom-tools:greet or /classroom-notes:greet. Both plugins contain greet, but their namespaces select different instructions and response markers.

05

Inspect optional manifests and failures

Compare a working manifest-free plugin with a nonexistent root and a corrupt manifest. A completed greeting does not mean the requested plugin loaded.

06

Share a bundle across projects

Load the same unchanged classroom-tools directory from two private working projects. Verify different project facts and the same plugin path. Agent discovery and MCP connection are observed; subagent and MCP tool execution are not demonstrated.
