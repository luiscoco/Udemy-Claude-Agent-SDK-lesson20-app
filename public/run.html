01

Prepare the project

Use Node.js 24+, npm, an Anthropic API key and model access. On Windows, install Git for the Bash runtime used by the SDK.

cd .\agent-sdk\lesson20-plugins
02

Install and configure

Install locked dependencies, preserve an existing .env and enter your key locally. The bundled MCP process uses the installed official MCP SDK.

npm ci
if (!(Test-Path .env)) {
  Copy-Item .env.example .env
}
notepad .env
03

Start the app

Open port 3120 and keep the terminal running. Navigate among the lab, learning goals, setup, UML and source walkthrough.

npm start
# http://127.0.0.1:3120
04

Load and verify

Run Absolute and Relative. Inspect the actual local roots, initialization, completed manifest Read and SessionStart hook receipt. Agent definitions and MCP connections are metadata observations, not execution claims.

npm run sample:env -- absolute
npm run sample:env -- relative
05

Compare namespaces and layout

Run Pair to dispatch two greet skills using different prefixes. Then run No manifest to observe component discovery without plugin.json. Inspect the actual saved plugin files.

npm run sample:env -- pair
npm run sample:env -- no-manifest
06

Troubleshoot and share

Run Missing and Invalid. Inspect the requested plugin’s absence and plugin_errors separately from an ordinary greeting result. Then run Share: projects A and B use the same unchanged plugin directory.

npm run sample:env -- missing
npm run sample:env -- invalid
npm run sample:env -- share
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3120
# Windows if needed: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

The startup script loads .env; shell variables take precedence. Restart after edits. No Managed Agents resource ID is required. Never share your real key.

Troubleshooting

If another service occupies the port, change PORT. A second start of this app prints its existing URL. On Windows set CLAUDE_CODE_GIT_BASH_PATH if Bash cannot be found. Keep optional npm dependencies enabled. A failed SDK result is retained as a failure. Check the plugin root, manifest JSON, readability and existence. Verify the namespaced skill layout. An ordinary successful answer does not establish plugin loading.
